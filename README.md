# Master Thesis – OpenMOC Simulations

This repository contains part of the open-source [OpenMOC](https://github.com/mit-crpg/OpenMOC) codebase, in particular material based on the `sample-input` directory provided with OpenMOC.

OpenMOC is an open-source neutron transport code based on the Method of Characteristics (MOC), developed for reactor physics calculations.

Most of the files and folders in this repository come directly from the original OpenMOC examples and benchmarks and have not been modified.
